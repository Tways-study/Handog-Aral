# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Handog Aral is a reading companion for Filipino children (ages 6–12, including children with dyslexia). A child scans a book page (or opens a built-in story), taps a word, and gets an explanation. There are two directions, chosen by the language setting: Filipino (`"tagalog"`, the default: the child reads English and gets Filipino meanings) and English (`"english"`: the child reads Filipino and gets English meanings). Hiligaynon was removed. It is a Next.js 16 (App Router) + React 19 + TypeScript + Tailwind v4 PWA, mobile-first with a real desktop layout, wrapped for Android with Capacitor. Product truth is in `PRODUCT.md`; the v3 plan and phase status are in `docs/v3-plan.md` (work is on branch `v3-overhaul`).

## Commands

```bash
npm install            # postinstall copies the self-hosted Tesseract assets into public/tesseract/ (needs network once)
npm run dev            # next dev (http://localhost:3000); /design is a dev-only showcase of the design system
npm run build          # web build (Vercel target), Serwist service worker enabled
npm start              # serve the production web build
npm run build:android  # BUILD_TARGET=capacitor next build && npx cap sync android
npm run typecheck      # tsc --noEmit
npm run lint           # eslint . (eslint-config-next)
npm test               # vitest run (jsdom)
npx vitest run src/lib/quiz.test.ts   # a single test file
npm run e2e            # playwright test (mobile 375x812 + desktop 1280x800)
```

**Two build targets, one codebase.** `next build` is the web target. `BUILD_TARGET=capacitor next build` is the Android target: `output: 'export'`, `trailingSlash`, unoptimized images, `pageExtensions: ['tsx']` (so every `route.ts` — the `/api/*` proxy and the Serwist route — is left out), no service worker. It writes to `out/`, which `capacitor.config.json` serves. The Android build calls the deployed proxy through `NEXT_PUBLIC_API_BASE`. The two builds share `.next`/`out`, so run one at a time and run the web build last.

**Private build dirs.** Set `NEXT_DIST_DIR=.next-<name>` to build or run `next dev` without clobbering `.next` (git-ignored). The Playwright e2e suite expects a production build in `.next-e2e` served on :3200: `NEXT_DIST_DIR=.next-e2e npm run build`, then `npx playwright test` (it reuses the server if one is up; keep workers ≤ 3). If Playwright's expected Chromium revision isn't installed, point `PW_CHROMIUM_PATH` at an installed one. Every e2e test stubs `/api/*` and dictionaryapi.dev; none may reach the real network.

**Env** (see `.env.example`): `NEXT_PUBLIC_SITE_URL` (metadataBase for social cards), `GEMINI_API_KEY`, `GEMINI_MODEL` (default `gemini-flash-latest`), `UPSTASH_REDIS_REST_URL`/`_TOKEN`, `ALLOWED_ORIGINS`, `NEXT_PUBLIC_API_BASE`. The key is server-side only; there is no in-app key entry. In production the proxy fails closed (503) without the Upstash vars; in development it allows all requests.

## Architecture

**Routes.** App Router with one thin server `page.tsx` per route rendering a `"use client"` screen from `src/features/<name>/`: `/` (Home), `/welcome` (first-run onboarding), `/books`, `/read/[bookId]` (ten bundled books via `generateStaticParams`: six English, four Filipino), `/scan`, `/words`, `/quiz`, `/settings`, `/offline`. `AppShell` (in `Providers`) renders the bottom nav below `lg` and a left rail at `lg`+; screens use `PageContainer`/`PageHeader` from `src/components/PageLayout`. Keep `window`/IndexedDB access out of module scope and server render. A `HydrationGate` in `Providers` shows `LoadingFrame` until the settings and progress stores have hydrated.

**State.** Persisted zustand stores over `idb-keyval`: `src/stores/settings.ts` (name, language, font size, dyslexia, TTS speed, overlay, theme, `onboarded`) and `src/stores/progress.ts` (current book, book progress, streak, quiz stars/high score, saved-word count). Heavier data is in Dexie (`src/stores/db.ts`, db `handog-aral`): `wordCache` (LRU 2000), `dictionary`, `filipino`, `lookupQueue`, `words` (saved vocabulary). Total stars = word stars (derived from saved-word count) + quiz stars; never overwrite one with the other. Always save/remove words through `learnWord`/`forgetWord` in `src/lib/vocabulary.ts` so book progress and star counts stay in sync. `ThemeSync` applies theme, `html.font-{small,medium,large}` and `body.dyslexia-font` from the settings store. `src/stores/migrate.ts` imports the pre-v3 `localStorage` blob once.

**Word-explanation pipeline** (`src/lib/dictionary/explain.ts`): word cache (unless the entry is `offline`) → curated dictionary (English words: `src/data/fallbackWords.ts` → Dexie `dictionary`; Filipino words in English mode: `src/data/filipinoWords.ts` → Dexie `filipino`; both seeded by `seed.ts`) → `/api/explain` (Gemini, prompt switches on direction) → dictionaryapi.dev + templated translation (English words only) → an honest provisional `offline` entry that is enqueued. `src/lib/queue/processor.ts` upgrades queued entries when back online (cache and saved words), and the open word panel swaps in place via a Dexie `liveQuery`. A newer tap must abort the older lookup. Results carry `source` (`ai|curated|dictionary|offline`) and the UI says so.

**AI proxy** (`src/app/api/{explain,ocr,health}/route.ts`, `src/server/*`, client in `src/lib/api.ts`). Shared zod contracts are in `src/shared/schemas.ts`. Per-IP Upstash rate limit (30/min explain, 6/min OCR), origin allowlist (always `https://localhost` and `capacitor://localhost`), size caps, 15s upstream timeout. The client returns `{ok, data} | {ok:false, reason:'offline'|'rate_limited'|'error'}`; `isReachable()` pings `/api/health` because `navigator.onLine` is not trusted.

**OCR** (`src/lib/ocr/`): `recognizePage` uses the proxy when online and reachable, otherwise local Tesseract with assets self-hosted under `public/tesseract/` (generated; git-ignored; cached by the `tesseract-assets` runtime cache and by `warmOfflinePack`). `OcrError` codes: `no_text`, `offline_pack_missing`, `aborted`, `failed`. Scans are cancellable and a stale scan must never overwrite a newer one. TTS (`src/lib/tts/`) uses `@capacitor-community/text-to-speech` natively and Web Speech elsewhere, sentence by sentence.

**Design system** (direction: Sticker Sheet, which replaced Pad Paper Storybook on 2026-10-22: a lilac page band with a barrio horizon scene (`BandScene`, CSS-only motion gated by `html[data-scenery]`), white sticker cards with a white keyline and soft lilac drop (`--sticker`), no ruled lines; contract in `.impeccable/surfaces/src-app-jsx.md`, comp in `.impeccable/mocks/home-reader-comp.html`). Tokens are CSS variables in `src/app/globals.css` (light and dark) exposed as Tailwind utilities (`bg-paper`, `text-ink`, `bg-sunrise`, jackets `bg-indigo|kangkong|mango|gumamela`, `border-line`, plus the shadcn names). `src/styles/contrast.test.ts` asserts WCAG contrast for the token pairs, so change colours there deliberately. Reading text sits on a plain white sheet: `.pad`/`.pad-text` (legacy class names for the sheet) tie line height to `--pitch`, which scales with the font-size class; keep text off the confetti. Difficulty is shown by shape and label (`DifficultyStamp`), never colour alone. Rules: no emoji or glyphs as icons (lucide only), no hard-coded hex in components, ≥44px touch targets, visible focus rings (`focus-visible:outline-solid` — in Tailwind v4 `outline-none` plus `outline-3` draws nothing), no hover-only affordances. Motion is GSAP via `src/lib/motion.ts` helpers, gated on `prefers-reduced-motion`, transform/opacity only, no looping decoration.

**Localization.** Child-facing strings are per feature in `src/data/strings/*.ts` (Filipino is the shape, English `satisfies` it), composed in `src/data/translations.ts`, read with `useT()`. Settings is an adults' screen and is in English. New child-facing text needs both languages. The `language` setting is also the lookup direction: `"tagalog"` taps English words (books in `sampleBooks`), `"english"` taps Filipino words (books in `src/data/filipinoBooks.ts`); `booksFor(language)` picks the shelf, `speechLang(language)` the TTS voice, and quiz/match only use words saved in the current direction. In `ResolvedExplanation`, `translation` is the explanation in the child's language and `english` is the definition in the tapped word's own language (a naming leftover).

**PWA.** Serwist via `@serwist/turbopack`: `next.config.ts` wraps the web config with `withSerwist`; `src/app/serwist/[path]/route.ts` builds `/serwist/sw.js` from `src/app/sw.ts` (precache + runtime rules: CacheFirst `/tesseract/*`, NetworkOnly `/api/*` — never cache the proxy, or offline detection breaks). Updates are prompt-based (a toast posts `SKIP_WAITING`). `src/app/manifest.ts` (id, shortcuts, screenshots) and icons in `public/icons/` (regenerate with `scripts/gen-pwa-icons.mjs`, Android launcher icons with `scripts/gen-android-icons.mjs`; social cards with `scripts/gen-og.mjs`; install screenshots in `public/screenshots/` with `scripts/gen-screenshots.mjs` against a running build; they are excluded from the precache). Security headers live in `next.config.ts` and are web-target only (`headers()` is unsupported with `output: 'export'`). `src/app/native.css` holds native-feel, forced-colors and prefers-contrast rules (globals.css owns the tokens). `not-found.tsx`/`error.tsx`/`global-error.tsx` are the in-world failure pages (strings in `src/data/strings/system.ts`). `InstallAppButton` + `useInstallPrompt` (hidden in Capacitor and when installed). Store boot: `src/stores/storage.ts` mirrors each persisted store into localStorage (`handog-mirror:*`, idb stays the source of truth) so the first client render has real settings; `Providers` loads migration, dictionary seed and the lookup queue lazily. e2e adds `a11y` (axe; `A11Y_STRICT=1` also enforces `label-content-name-mismatch`), `system-pages`, `security-headers`, `boot-timing`. Release steps: `docs/release-checklist.md`.

**Owl, rewards and moments (the "fun and cute" layer).** Always render the owl through `src/components/owl/Owl.tsx`: it shows the flat SVG `Mascot` immediately and lazily upgrades to a procedural three.js owl (`Owl3DCanvas`, ~139 KB gzipped, one lazy chunk) only when allowed — setting `owl3d` on, WebGL available (not software), no reduced motion / save-data / slow connection / very low-end device, the page loaded and idle, and nothing failed earlier in the session (`src/lib/owl/capability.ts`, `loadGate.ts`). At most ONE owl per page runs 3D (`priority="hero"` wins, owls < 72 px never do; `src/lib/owl/slots.ts`); rendering is demand-driven (a GSAP ticker listener only while a tween runs). Optional lazy pieces must use `softDynamic` (`src/lib/softDynamic.ts`) so a chunk that cannot be fetched offline renders nothing instead of tripping the error boundary. Rewards live in `src/stores/rewards.ts` (earned stickers, bonus stars) with pure rules in `src/lib/stickers/` — emit `useRewards.getState().recordEvent({type: ...})` (`word-saved`, `scan-done`, `listen`, `quiz-finished`, `streak`, `book-progress`, `book-opened`, `match-won`); new stickers queue a celebration (`src/components/celebration/`, lazy host). One-time "first time" moments (first tap, first save, first scan, first quiz) are flags in `src/stores/moments.ts`. Sticker art is `StickerArt` (ids in `src/lib/stickers/ids.ts`); sounds are synthesized (`src/lib/sound.ts`, off by default) and haptics are `src/lib/haptics.ts`. Routes `/stickers` (sticker book + owl wardrobe) and `/play` (untimed memory match from saved words). Welcome ends with a "first superpower" step that uses the real word panel offline. The owl's look follows the reference sheet `public/mascot/owl-expression-sheet.png` (chubby egg, cream goggle eyes, rosy cheeks, no outline); its palette lives in `OWL` (`src/components/art/OwlGroup.tsx`) and is mirrored in the 3D model (`owlModel.ts`); icons and social cards regenerate from it. New copy in the owl's voice is marked `// REVIEW: native speaker` in `src/data/strings/*`.

## Repo notes

- `.agent.md` is a read-only "Senior Code Reviewer" agent profile (camelCase variables, PascalCase components, validate external input with Zod).
- `.impeccable/` holds the design direction, the approved comp and review screenshots; `PRODUCT.md` is the product record.
- ESLint ignores unused variables that start with an uppercase letter or `_`, and ignores `public/tesseract/**` and `.next-*/**`.
- Offline dictionary expansion (`scripts/build-dictionary.ts`, `src/data/dictionary.v1.json`, ~2,000 words) is not built yet; it needs a `GEMINI_API_KEY` locally. Generated entries must carry `reviewed: false` until a native speaker checks them.
